## Висновок
Під час виконання лабораторної роботи я навчилася працювати з двозв’язними списками в C++ за допомогою контейнера std::list та ітераторів.
На практиці я закріпила додавання (push_front, push_back), видалення (erase), пошук і сортування (sort) елементів як для звичайних чисел, так і для власної структури Medicine згідно з варіантом 7. Зрозуміла, як правильно переміщуватися списком за допомогою ітераторів (std::prev) та безпечно видаляти елементи під час перебору, не втрачаючи доступ до решти списку.
